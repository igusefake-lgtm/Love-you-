MANTASHA — 100 LANGUAGES BIRTHDAY EXPERIENCE

Open index.html in any browser. No photos or installation needed. Internet is only needed for Google Fonts; system fonts are used as fallback.

The heart animation uses a list of 100 phrases in different languages. Some languages have gendered variants; translations can vary by region.

To publish on GitHub Pages: upload index.html, style.css, script.js to a repository, then Settings → Pages → Deploy from branch → main / root.

Personalize the messages in script.js under modalData.
